1. Зашумлённое

Гауссов + импульсный шум - для медианного и сглаживающего фильтров.

2. Размытое

Размыто гауссом - для повышения резкости (unsharp/лаплас).

3. Малоконтрастное

Узкий диапазон яркостей - для контрастирования и эквализации.

4. Текст, неравномерный фон

Глобальный порог не справится - для Sauvola/Wolf.

5. Мелкие детали на неоднородном фоне

Для морфологического Top-Hat / Black-Hat.

6. Границы и углы

Для Sobel / Canny с картой направлений.

Архитектура приложения

  1. Presentation Layer (UI) - canvas, слайдеры, прогресс-бар.
  2. Memory & Pixel Access Layer - класс ImageBuffer, честный побайтовый доступ к Uint8ClampedArray / Float32Array, обработка краёв (Reflect / Clamp).
  3. Processing Layer - чистые математические функции над буферами. Не зависят от UI.

Реализованные алгоритмы

  • Поэлементные (LUT): яркость, контраст, гамма.
  • Линейное контрастирование (по 2%/98% перцентилям).
  • Эквализация RGB и HSV (V-канал).
  • CLAHE (тайлы + clip limit + билинейная интерполяция).
  • Глобальный порог, Отсу (межклассовая дисперсия).
  • Sauvola, Wolf - через интегральное изображение (SAT).
  • Гаусс и Box - разделяемая свёртка O(K·N²).
  • Unsharp Mask, Лапласиан.
  • Медианный фильтр (порядковая статистика).
  • Sobel (модуль и карта направлений через HSV).
  • Canny с субпиксельной локализацией.
  • Морфология: Erode/Dilate/Open/Close/Gradient/Top-Hat/Black-Hat.
  • Многопоточная свёртка (Web Worker, полосы изображения).

Обработка краёв

Reflect (REFLECT_101): индекс отражается без дублирования границы - плавные переходы.

Clamp: индекс зажимается к граничному - сохраняет уровень фона, но даёт «плато» на краях.
